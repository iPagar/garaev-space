## From a personal photo to a mug design

MugMeme is an iPhone application for creating custom mug designs from photos. The starting material can be a selfie, a pet picture or a photograph of a friend; the output is a digital design that the user can preview and export.

The product challenge is to make image generation part of a recognisable creative sequence. Selecting an image is only the beginning: the user also needs a direction for the design and a way to understand how it will look on a curved object.

## Making the result tangible

The application connects photo selection, AI styles and a three-dimensional mug preview. The preview bridges the gap between a flat image and the object the user has in mind.

The interface keeps the creative work focused on the source photo and the generated result. Export provides a clear endpoint: an image the user can save, share or take to a printing service.

![MugMeme promotional image showing the design and preview experience](/case-studies/mugmeme-2.webp)

## Connecting generation, preview and export

The project combines a React Native mobile interface with a backend for the image-generation workflow. The application also integrates subscription access, so generation and the surrounding product experience operate within the same app.

High-resolution export is a distinct part of the workflow. MugMeme creates the digital artwork; the application does not manufacture or ship physical mugs.

![An additional official MugMeme App Store promotional screen](/case-studies/mugmeme-3.webp)

## The result

MugMeme is available on the App Store as an independent product. It demonstrates an end-to-end creative application: a personal input, an AI transformation, a contextual preview and an exportable result.
