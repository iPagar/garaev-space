## A focused tool for work on a computer

I develop desktop applications for tasks that benefit from local files, operating-system features or a dedicated workspace. The scope can be a compact utility used throughout the day or an application for collecting, reviewing and exporting information.

The product should fit the task: a menu bar tool and a data workspace need different interfaces and different kinds of integration with the computer.

## What you can bring

- A recurring workflow needs a dedicated interface for working with local data or files.
- Your team needs to inspect records, run a process and export the results to a spreadsheet.
- A utility needs access to system information or a place in the macOS menu bar.
- A collection of scripts needs an application interface that colleagues can use directly.

## What I can build

The scope can include the application interface, local storage, background processing, file import and export, and connections to external services. Progress, cancellation and clear results make longer operations manageable from the same workspace.

I work with Electron and React for desktop interfaces and native Swift for macOS tools. The choice follows the required platforms, system access and interaction model.

## How the work is scoped

We begin with the recurring task, representative files or records, and the operating systems the application needs to support. I map what should remain local and which steps depend on a network service.

Implementation covers the main workflow and practical states such as an empty dataset, a cancelled operation or an unavailable connection. Packaging and installation are considered alongside development so the tool can be delivered to its intended users.

## What you receive

A desktop application for the agreed platform and workflow, with installation instructions and documentation for its configuration. Distribution, signing and a maintenance plan can be included according to the project’s needs.

To start, share the process you want to simplify, the data it uses and where the application will run.
